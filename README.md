# Cocktail SOP Studio | 智慧調酒規格表與流程圖生成系統

為專業調酒吧、餐飲研發團隊量身打造的調酒標準化作業流程（SOP）規格卡生成網頁。支援丟入任何形式的資料（雜亂筆記、Excel 複製、CSV、檔案拖放、甚至語音文字），自動秒級生成嚴格依循標準規格設計的調酒 SOP 規格卡，並支援 5 大格式無損匯出。

---

## 🌟 核心特色功能

### 1. 嚴格 1:1 格式還原
* **專業規格版型**：經典灰色標題欄（`#c8cbce`）、清晰黑色網格框線、高對比易讀排版。
* **完整欄位結構**：
  * **左側**：酒名標題、調酒成品照片、出杯作法（冰塊、容量、噴霧）、裝飾物說明、成本率。
  * **中間**：材料名稱、總容量 (ml)、酒精濃度 (abv)、單價、單位、小計，以及底部自動連動的「總計」、「每份容量/總份數」、「單杯成本」。
  * **右側**：完整批次預製作法、自製材料浸漬/舒肥/冷泡/糖漿步驟（跨行統一對齊）。

### 2. 萬能資料輸入 (不限任何形式)
* **任意文字輸入**：直接貼上酒吧通訊軟體對話、工作筆記、非結構化文字，內建本地 NLP 語意解析器自動提取酒名、材料容量、作法與自製配方。
* **試算表直接貼上**：支援從 Excel、Google Sheets 直接複製表格貼上，自動識別分欄與數據。
* **檔案拖放上傳**：支援拖放或點擊上傳 `.xlsx`、`.xls`、`.csv`、`.txt`，甚至直接拖入調酒成品圖片！
* **雙引擎智能支援**：
  * **本地快速引擎**：完全離線、免裝軟體、0 延遲秒級解析。
  * **Gemini AI 智能模式**：可填入 Gemini API Key，支援極端口語化、多國語言混合、甚至手寫轉文字深度結構化提取。

### 3. 所見即所得・線上即時微調
* 表格上的每一個格子均支援點擊直接編輯（Contenteditable）。
* 數字（容量、單價、份數）修改後，自動重新計算總容量、加權酒精濃度 (ABV)、小計、份數與單杯成本。
* 調酒照片支援：點擊更換、檔案拖放、或在頁面上直接按 `Ctrl+V` 貼上螢幕截圖！

### 4. 5 大格式一鍵無損匯出
* 📄 **PDF**：高解析度 A4 橫式向量規格書，邊框清晰銳利，適合列印歸檔。
* 📊 **EXCEL (.xlsx)**：完整包含儲存格合併、標題底色、邊框、數值計算公式與調酒照片嵌入。
* 📝 **WORD (.docx / .doc)**：標準 Word 規格表格文件，可直接二次排版與編輯。
* 🖼️ **PNG**：Retina 3x 超清解析度透明/白底圖檔，適合傳到 LINE 群組或手機查看。
* 🎨 **JPG**：95% 高品質白底圖檔。
* 🖨️ **列印模式**：內建 A4 橫向最佳化列印樣式，按 `Ctrl+P` 自動隱藏所有側邊欄與按鈕。

## 🚀 如何啟動使用

本系統採用純前端原生架構，所有相依套件均已內建於 `libs/` 目錄中，**不需安裝 Node.js、Python 或任何環境**：

1. **直接啟動**：在資料夾中雙擊 `啟動調酒SOP系統.bat` 或直接用瀏覽器開啟 `index.html`。
2. **一鍵載入範本**：點擊左側「🍹 No3. Jasmine melon」按鈕，立即查看與標準規格 100% 吻合的範本！
3. **丟入資料**：在文字框貼上您的配方，點擊「🚀 生成 SOP 流程圖」。
4. **選擇匯出**：在右上角工具列點擊「PDF / EXCEL / WORD / PNG / JPG」即可立即下載！
